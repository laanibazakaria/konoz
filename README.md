# مسابقة المسلم الصغير

لعبة أسئلة إسلامية تعليمية للأطفال: خريطة مستويات، أسئلة بثلاثة خيارات، نجوم وقطع ذهبية، ولوحة إدارة لإضافة الأسئلة ومراجعتها.

```
quiz_islami/
├── app/        تطبيق الجوال (Flutter) — Android و iOS و Web
├── admin/      لوحة الإدارة (React + Vite)
└── supabase/   قاعدة البيانات (PostgreSQL): المخطط، القواعد، البيانات الأولية، الاختبارات
```

## 1. قاعدة البيانات (Supabase)

1. أنشئ مشروعاً على [supabase.com](https://supabase.com).
2. في **SQL Editor** نفّذ بالترتيب:
   - `supabase/migrations/0001_init.sql` (الجداول، قواعد RLS، دالة حساب النتيجة)
   - `supabase/seed.sql` (3 عوالم، 3 مستويات، 15 سؤالاً للتجربة)
3. في **Authentication → Providers** فعّل **Anonymous sign-ins** (ليلعب الأطفال دون بريد إلكتروني).
4. أنشئ حساب المشرف من **Authentication → Users → Add user**، ثم امنحه الصلاحية:

```sql
update public.profiles set role = 'admin'
where id = (select id from auth.users where email = 'you@example.com');
```

الأدوار: `player` (لاعب)، `editor` (يضيف ويعدّل، لا ينشر)، `admin` (يراجع وينشر).

## 2. تطبيق الجوال

```bash
cd app
flutter pub get
flutter run --dart-define=SUPABASE_URL=https://xxxx.supabase.co --dart-define=SUPABASE_ANON_KEY=xxxx
```

بدون `--dart-define` يعمل التطبيق في **الوضع التجريبي** ببيانات محلية، وهذا مفيد لتجربة الواجهة.

### الصور

التطبيق يعمل بدون صور (رسومات بديلة بالكود). لاستخدام رسوماتك، ضع الملفات بهذه الأسماء:

| الملف | الاستخدام |
|---|---|
| `assets/characters/mascot.png` | الشخصية (الوحش البنفسجي) |
| `assets/ui/parchment.png` | لوحة السؤال (رقّ) |
| `assets/ui/wood_card.png` | بطاقة الإجابة الخشبية |
| `assets/backgrounds/quiz_*.png` | خلفيات شاشة السؤال (تُحدَّد لكل عالم في جدول `worlds`) |
| `assets/backgrounds/map_*.png` | خلفيات الخريطة |
| `assets/backgrounds/home.png` | الشاشة الرئيسية |

> استخدم رسومات من إنتاجك أو حزماً مرخّصة تجارياً، لا صوراً مأخوذة من تطبيقات أخرى.

## 3. لوحة الإدارة

```bash
cd admin
cp .env.example .env.local   # ضع رابط المشروع والمفتاح العام
npm install
npm run dev
```

الميزات: إدارة المستويات (العنوان، العالم، القطع، النشر)، إضافة وتعديل وحذف الأسئلة مع معاينة مباشرة بشكل التطبيق، اختيار الإجابة الصحيحة، إعادة الترتيب، مسار المراجعة (مسودّة ← قيد المراجعة ← منشور)، واستيراد CSV.

للنشر: `npm run build` ثم ارفع مجلد `dist/` إلى Vercel أو Netlify.

## 4. النشر على الإنترنت (موقع قابل للتثبيت على الهاتف)

اللعبة تُنشر كموقع ويب **قابل للتثبيت كتطبيق (PWA)**، تلقائياً عبر GitHub Actions عند كل `push` على `main`:

- اللعبة: `https://<الحساب>.github.io/<المستودع>/`
- لوحة الإدارة: `https://<الحساب>.github.io/<المستودع>/admin/`

**مرة واحدة فقط:** في GitHub ← **Settings → Pages → Source** اختر **GitHub Actions**.

**ربط Supabase:** في **Settings → Secrets and variables → Actions → Variables** أضف `SUPABASE_URL` و `SUPABASE_ANON_KEY`. بدونهما تعمل اللعبة في الوضع التجريبي.

**التثبيت على الهاتف:** زر «ثبّت التطبيق على هاتفك» في الشاشة الرئيسية للعبة
(Android وكمبيوتر عبر Chrome/Edge). على iPhone يعرض الزر الخطوات: Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».

أيقونات التطبيق تُولَّد بالأمر `python3 tool/make_icons.py`.

## قواعد اللعبة

- **النجوم**: ‏100% → 3 نجوم، ‏70% → 2، ‏40% → 1.
- **فتح المستويات**: يُفتح المستوى التالي بعد الحصول على نجمة واحدة على الأقل.
- **القطع**: `عدد الإجابات الصحيحة × coins_per_correct`، وتُمنح **فقط عند تحسين النتيجة** (لمنع تكرار المستوى لجمع القطع).
- النتيجة تُحسب **على الخادم** (`submit_attempt`)؛ التطبيق يرسل الإجابات فقط.
